# Media attribution

Verify and document licenses before production marketing use.

| File | Status |
|------|--------|
| `public/images/hero-clinic.jpg` | **Requires verification** — no license on file in-repo. Confirm you have commercial rights (stock license, original photo, or clinic-owned). Prefer renaming to the true format if the file is PNG bytes. |
| `public/images/profile.png` | **Requires verification** — unused orphan asset; remove or document license. |
| `public/Queue.jpg` | **Requires verification** — unused orphan if present; remove or document license. |
| Lucide icons | ISC license via `lucide-react` |
| DM Sans / DM Serif Display / JetBrains Mono / Inter | Loaded via `next/font/google` (typically OFL / SIL); see Google Fonts license pages |

Do not treat CareQ as shipping cleared stock photography until this file is updated with purchase IDs or photographer credits.
